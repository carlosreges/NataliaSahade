# Natalia Sahade - Coaching Profesional

Sitio web profesional para Natalia Sahade, coach certificada con más de 10 años de experiencia ayudando a personas y profesionales a alcanzar su máximo potencial.

## Características Principales

- Diseño completamente responsive
- Secciones informativas sobre servicios de coaching
- Testimonios reales de clientes
- Blog con artículos sobre desarrollo personal
- Formulario de contacto integrado
- Botón flotante de WhatsApp para consultas rápidas
- Optimizado para SEO

## Tecnologías Utilizadas

- HTML5, CSS3, JavaScript
- Bootstrap 4
- jQuery
- Font Awesome
- Owl Carousel
- Magnific Popup

## Personalizaciones Realizadas

- Diseño completamente renovado y adaptado a la marca personal
- Contenido original creado específicamente para el coaching
- Integración con redes sociales profesionales
- Formularios de contacto personalizados
- Sección de testimonios reales
- Optimización de rendimiento

## Instalación

1. Clonar el repositorio:
```bash
git clone https://github.com/tu-usuario/natalia-coach.git
```

2. Abrir el archivo `index.html` en tu navegador preferido
